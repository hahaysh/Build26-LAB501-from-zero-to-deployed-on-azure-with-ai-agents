# 사전 준비

**랩 VM에 미리 준비된 항목:**

- Contributor 권한의 Azure subscription
- LEGO 데이터셋이 들어있는 **사전 프로비저닝 Cosmos DB** 계정
- GitHub Copilot CLI
- [Python 3.13+](https://www.python.org/)
- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- [Git](https://git-scm.com/)
- [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli) + Bicep (`az bicep install`)
- [Azure Developer CLI (azd)](https://learn.microsoft.com/azure/developer/azure-developer-cli/install-azd)
- Azure MCP Server

> 💡 실습은 Skillable VM 기준으로 작성되어 있습니다. 개인 환경에서 진행하는 경우 버전 차이로 명령 결과가 달라질 수 있습니다.
